# Decision Compression

You are not summarising everything. You are selecting what matters to the decision.

## Preserve
- recommendation
- strongest reasons
- viable alternatives
- material trade-offs
- material engineering risks
- important unknowns
- evidence supporting important claims
- conditions that would change the recommendation
- implementation next steps

## Remove
- research chronology
- search history
- duplicated evidence
- trivial differences
- dead-end options
- speculative detail that does not affect the decision
- low-value implementation minutiae

## Decision-value test
Include a finding in the main response only if it:
1. changes which option wins
2. explains why the winner wins
3. explains a meaningful trade-off
4. identifies a material risk
5. identifies meaningful uncertainty
6. changes implementation strategy
7. could reasonably change the user's decision

## Final test
The user must be able to answer:
- What should I do?
- Why?
- What do I give up?
- What could go wrong?
- What do I do next?
- What would change the decision?

Be comprehensive in investigation. Be selective in communication.

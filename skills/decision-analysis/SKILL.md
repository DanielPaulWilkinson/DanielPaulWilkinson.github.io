# Decision Analysis

## Derive criteria from the goal
Typical criteria:
- goal fit
- implementation complexity
- maintainability
- security
- testability
- reliability
- performance
- scalability
- developer experience
- ecosystem maturity
- cost/TCO
- reversibility

Do not use criteria that do not matter to the goal.

## Weighting
Use weights totalling 100% when scoring adds value. Explain important weighting decisions.

## Scoring
Use 1–10 as a decision aid, not scientific precision.

## Hard constraints
Any option that violates a hard requirement is disqualified.

## Qualitative judgement
Explain what actually drives the result. Do not hide behind score arithmetic.

## Sensitivity
Identify assumptions or weight changes that could make another option win.

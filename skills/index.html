Skill library

Short, plain-English instructions that any AI agent can fetch by URL and follow. Each one is a single Markdown file. Free to use; credits are inside each file.

How to use these with your agent

Paste this into your agent's chat, or into its standing instructions:

Fetch https://danielpaulwilkinson.github.io/skills/index.json, pick the skill that fits this task, fetch its SKILL.md and follow it.

  1. The agent reads index.json, a list of every skill with a one-line "use it when".
  2. It fetches the matching SKILL.md. If its tools won't read .md, each skill has a SKILL.txt copy.
  3. It follows the steps. You stay in charge: none of these skills send, buy or publish anything without your yes.

Also listed in llms.txt for agents that look there first.

Goal analysis

Turns a software engineering objective into a precise outcome, requirements, hard and soft constraints, success criteria, assumptions, unknowns, and concrete technical decisions to investigate.

Point your agent at this file

Raw SKILL.md Plain text copy Version 1.0.0, updated 6 November 2026

Do not solve the problem yet. Define it precisely.

Determine

  • desired outcome
  • business/user value where stated
  • functional requirements
  • non-functional requirements
  • hard constraints
  • soft preferences
  • success criteria
  • current-state assumptions
  • unknowns that could change the decision
  • decisions that must be made

Software-engineering lenses

Consider, where relevant:

  • runtime/platform constraints
  • existing architecture and codebase constraints
  • language/framework versions
  • API/interface compatibility
  • data and persistence
  • security/compliance
  • performance/SLOs
  • deployment/environment constraints
  • team skills and ownership
  • testing requirements
  • observability and support
  • migration/rollback requirements
  • budget/licensing

Questions

Only interrupt for information that could materially change the recommendation. Otherwise state assumptions and continue.

Challenge

Adversarially challenges a software engineering recommendation to uncover confirmation bias, weak assumptions, overlooked architectures, hidden costs, security issues, maintainability problems, and scenarios where another option wins.

Point your agent at this file

Raw SKILL.md Plain text copy Version 1.0.0, updated 6 November 2026

Actively try to prove the current recommendation wrong.

Attack it from these angles

  • strongest case for the runner-up
  • contradictory technical evidence
  • hidden implementation effort
  • hidden operational burden
  • security weaknesses
  • testing difficulty
  • ecosystem maturity
  • lock-in
  • future scaling
  • migration/rollback difficulty
  • over-engineering
  • under-engineering
  • assumptions carrying the most weight
  • bias toward familiar/new/popular technologies

Outcome

Survives

Recommendation remains strongest.

Weakened

Recommendation remains strongest but confidence decreases.

Changed

Another option is superior. Change the recommendation.

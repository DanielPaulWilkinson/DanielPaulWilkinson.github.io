Investigation

Performs evidence-based software engineering research covering technologies, libraries, frameworks, architectures, APIs, benchmarks, compatibility, security, ecosystem maturity, cost, failure modes, and real-world practice.

Raw SKILL.md Plain text copy Version 1.0.0, updated 6 November 2026

Determine what is actually true.

Research each serious option

Investigate where relevant:

  • capabilities
  • limitations
  • compatibility/version support
  • architecture characteristics
  • integration effort
  • performance evidence
  • reliability characteristics
  • security posture
  • testing implications
  • deployment/operations
  • ecosystem maturity
  • documentation/support
  • licensing
  • cost/TCO
  • migration/exit path
  • known failure modes

Source priority

  1. official docs/specs
  2. standards/primary sources
  3. reputable technical publications
  4. practitioner experience
  5. community discussion
  6. general web content

Contradiction hunting

Search for limitations, outages, security issues, migration pain, lock-in, poor developer experience, and credible alternatives.

Evidence classification

Label important findings as Fact, Inference, or Opinion and rate confidence High/Medium/Low.

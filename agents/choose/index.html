When three agents look similar

  • Architect vs Technical Investigator. Architect produces design artefacts (diagrams, API contracts, data models, ADRs) and evaluates technology choices; it never writes or edits application code. Technical Investigator diagnoses complex or systemic problems with evidence, maps options, and recommends a path; it is read-only and hands implementation to Implementer.
  • Pathfinder vs Technical Investigator. Pathfinder decides the best practical path for achieving an engineering goal (architecture, technology selection, implementation strategy, migrations, process, tooling). Technical Investigator investigates a non-trivial technical problem that already exists — complex bugs, architectural issues, intermittent failures — and researches solution options for that problem.

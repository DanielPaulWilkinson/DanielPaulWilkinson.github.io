Agent library

Ready-made agent definitions for software work. Each is a VS Code / GitHub Copilot custom agent file, with a converted Claude Code subagent alongside. Many follow steps from the skill library.

How to install

  1. VS Code / GitHub Copilot: save the file as .github/agents/<name>.agent.md in your repo, then pick the agent in Chat.
  2. Claude Code: save the .claude.md variant as .claude/agents/<name>.md (or in ~/.claude/agents/ for every project).
  3. Programs: read index.json; each agent lists its url, install_path, Claude Code variant, skills and handoffs.

Install every Copilot agent at once (needs jq; run mkdir -p .github/agents first):

for a in $(curl -fsSL https://danielpaulwilkinson.github.io/agents/index.json | jq -r '.agents[].name'); do curl -fsSL https://danielpaulwilkinson.github.io/agents/$a/$a.agent.md -o .github/agents/$a.agent.md; done

No model is pinned, so each agent uses your default. Read an agent before installing it: they can run tools in your repo. Also listed in llms.txt.
